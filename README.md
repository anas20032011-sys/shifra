# لعبة الشفرة السرية

لعبة جماعية مباشرة: فك الشفرة بالخريطة، اقرع الجرس، وأجب قبل غيرك.

- الموقع: https://anas20032011-sys.github.io/shifra/
- `index.html`: اللعبة كاملة في صفحة واحدة.
- `firestore.rules`: قواعد Firestore المطلوبة لمسار اللعبة `g`، تُضاف داخل قواعد المشروع.

## نظام التصميم

كل الأنماط في `index.html` داخل `<style>` ومقسّمة بتعليقات مرقّمة:

- **الرموز (Tokens):** الألوان (كحلي داكن، فيروزي للإبراز `--acc`، أحمر داكن، أخضر)، الزوايا، الظلال، المسافات، والحركة كمتغيرات CSS في `:root`.
- **المكوّنات:** البطاقات الزجاجية `.card` وبطاقة الملف `.case`، الأزرار (افتراضي فيروزي، `.s` ثانوي، `.g` نجاح، `.r` تنبيه)، الشارات `.chip`، المؤقت `.timer`، وحالات اللعبة `.st-wait / .st-turn / .st-ok / .st-err`.
- **الأيقونات:** مجموعة SVG موحدة في الكائن `IC` تُرسم بالدالة `I(name)`.
